HostelCMS

Hostel Complaint
Management System

Students can submit hostel complaints. Admins can view and resolve them. Secure login for both roles.

Two Portals, One System

🎓

Student Portal

Log in to submit and track your hostel complaints from start to resolution.

  • Submit complaints with details
  • Track status in real time
  • View complaint history
  • Get admin responses
🛡️

Admin Portal

Log in to view all student complaints and mark them as resolved.

  • View all complaints
  • Update complaint status
  • Add resolution remarks
  • Filter by category or date

How It Works

01

Student Logs In

Authenticate securely using hostel credentials.

02

Submit Complaint

Fill in category, room number, and description.

03

Admin Reviews

Admin sees all complaints and updates the status.

04

Issue Resolved

Student sees the update. History is preserved.
